🍽️ Labelezza - Sistema de Restaurante
Labelezza é um sistema completo para simulação da rotina de um restaurante. Este foi meu primeiro projeto de 2025, desenvolvido com HTML, CSS, Bootstrap e JavaScript, com foco em usabilidade, organização e fluxo de trabalho integrado entre os setores do restaurante.

🔧 Tecnologias Utilizadas
HTML5

CSS3

Bootstrap 5

JavaScript (puro)

🧩 Funcionalidades
👨‍💼 Gerente
Define o cardápio do dia.

Possui opção para adicionar mais itens ao estoque.

🛎️ Recepcionista
Realiza a reserva de mesas.

Faz a liberação de mesas quando desocupadas.

🍽️ Garçom
Visualiza o cardápio definido pelo gerente.

Registra pedidos informando o número da mesa.

Finaliza o pedido, que é enviado automaticamente para a cozinha.

🔪 Cozinha
Recebe os pedidos finalizados, identificando o número da mesa e os itens solicitados.

💵 Caixa
Consulta o número da mesa e obtém o valor total do pedido.

Seleciona a forma de pagamento (ex: dinheiro, cartão).

Calcula troco, se necessário.
